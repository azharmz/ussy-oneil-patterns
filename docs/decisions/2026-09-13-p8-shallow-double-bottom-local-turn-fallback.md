# P8 shallow Double Bottom local-turn fallback

Date: 2026-09-13
Status: DEVELOPMENT REVISION

## Evidence

The expanded authoritative DEVELOPMENT corpus includes Walmart 2024, explicitly described by IBD as a mild Double Bottom with a 60.89 entry, first low 58.88 and second low 58.55. The frozen P1 8% excursion scale emitted no W geometry for that example.

IBD's Double Bottom guidance sets a seven-week minimum and a maximum depth, but does not define an 8% minimum reversal as an identity requirement. Therefore the inability to represent a shallow W is a structural-candidate scale problem, not evidence that the authoritative label is invalid.

## Revision

Canonical DEVELOPMENT v1.1 keeps frozen P1 as the primary structural source. Only when P1 produces no Double Bottom geometry at all, a fallback enumerates strict local extrema using:

- three later sessions for causal confirmation;
- zero percentage-amplitude floor beyond being a strict local extremum;
- the same downstream Double Bottom geometry, duration, depth and ambiguity assessment;
- explicit `LOCAL_TURN_AUX` candidate semantics.

This fallback is label-agnostic. It does not use source pivot, source dates, detector outcome or returns to locate turns.

## Guardrails

- P1 is not silently refrozen or replaced.
- The auxiliary path is DEVELOPMENT-only pending P8 evidence.
- The 35-session Double Bottom minimum is unchanged.
- The 40% maximum depth is unchanged.
- Undercut and middle-rebound faults remain explicit.
- No return, CAGR, PF, FWD1, breakout-success or VALIDATION information is used.
